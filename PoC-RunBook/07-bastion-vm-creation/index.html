This section creates a bastion VM in the assigned PoC compartment through ADMIN_COMPARTMENT_OCID using the approved admin subnet and bastion NSG. The VM is the controlled administration host for SSH, SQL*Plus, SQL Loader, RMAN client utilities, JDBC testing, and Java-based database tools.

Section purpose

This section creates a bastion VM in the assigned PoC compartment through ADMIN_COMPARTMENT_OCID using the approved admin subnet and bastion NSG. The VM is the controlled administration host for SSH, SQL*Plus, SQL Loader, RMAN client utilities, JDBC testing, and Java-based database tools.

Required inputs

Variable Expected value
ADMIN_COMPARTMENT_OCID Assigned PoC compartment alias for administration resources.
SUBNET_ADMIN_OCID Admin subnet OCID.
NSG_BASTION_OCID Bastion/admin NSG OCID.
AVAILABILITY_DOMAIN Target availability domain for the VM. This chapter resolves the tenancy-specific AD1 name.
BASTION_SHAPE Compute shape approved for admin tooling, for example VM.Standard.E5.Flex.
BASTION_OCPUS Flex OCPU count for the bastion VM.
BASTION_MEMORY_GBS Flex memory for the bastion VM.
OL9_MARKETPLACE_IMAGE_OCID Oracle Linux 9 image OCID. This chapter resolves the newest Oracle Linux 9 platform image compatible with the bastion shape in the region loaded from cli.env.
SSH_PUBLIC_KEY_FILE Public RSA SSH key file used for the opc user. This follows Oracle's documented OpenSSH RSA example for OCI Linux instances.

Set bastion inputs

The command below resolves the newest Oracle Linux 9 platform image compatible with BASTION_SHAPE in the region loaded from ~/workbook/cli.env. Filtering by shape prevents selecting GPU or other shape-incompatible images.

For SSH keys, OCI documents that OCI Console-generated Linux instance keys are RSA OpenSSH key pairs. Oracle's manual ssh-keygen example uses ssh-keygen -t rsa -N "" -b 2048 -C "<key_comment>", so this workbook mirrors that format.

BASH 01 - Set bastion inputs

Bash
Objective: Create or verify the workbook FIPS-compatible RSA SSH key pair, resolve AD1, and set a shape-compatible Oracle Linux 9 image OCID. 
wb07_card01() {
clear
  . ~/workbook/env.sh --quiet || return 1

WORKBOOK_DIR="${WORKBOOK_DIR:-$HOME/workbook}"
SSH_PRIVATE_KEY_FILE="${WORKBOOK_DIR}/bastion-01_rsa"
SSH_PUBLIC_KEY_FILE="${SSH_PRIVATE_KEY_FILE}.pub"
BASTION_SHAPE="${BASTION_SHAPE:-VM.Standard.E5.Flex}"

if [ ! -s "$SSH_PRIVATE_KEY_FILE" ]; then
  ssh-keygen -t rsa -N "" -b 2048 -C "bastion-01 key" -f "$SSH_PRIVATE_KEY_FILE"
elif [ ! -s "$SSH_PUBLIC_KEY_FILE" ]; then
  ssh-keygen -y -f "$SSH_PRIVATE_KEY_FILE" > "$SSH_PUBLIC_KEY_FILE"
else
  printf 'Reusing existing RSA key pair: %s\n' "$SSH_PRIVATE_KEY_FILE"
fi

chmod 600 "$SSH_PRIVATE_KEY_FILE"
chmod 644 "$SSH_PUBLIC_KEY_FILE"

AVAILABILITY_DOMAIN="$(
  oci iam availability-domain list \
    --region "$REGION" \
    --compartment-id "$TENANCY_ID" \
    --query "data[?contains(name, 'AD-1')].name | [0]" \
    --raw-output
)"

OL9_MARKETPLACE_IMAGE_OCID="$(
  oci compute image list \
    --region "$REGION" \
    --compartment-id "$TENANCY_ID" \
    --operating-system "Oracle Linux" \
    --shape "$BASTION_SHAPE" \
    --sort-by TIMECREATED \
    --sort-order DESC \
    --query 'data[?contains("display-name", `Oracle-Linux-9`)] | [0].id' \
    --raw-output
)"

for required_value in AVAILABILITY_DOMAIN OL9_MARKETPLACE_IMAGE_OCID SSH_PUBLIC_KEY_FILE SSH_PRIVATE_KEY_FILE; do
  if [ -z "${!required_value}" ] || [ "${!required_value}" = "null" ]; then
    printf 'Unable to resolve %s\n' "$required_value" >&2
    return 1
  fi
done

upsert_cli_env AVAILABILITY_DOMAIN "$AVAILABILITY_DOMAIN" >/dev/null
upsert_cli_env BASTION_SHAPE "$BASTION_SHAPE" >/dev/null
upsert_cli_env OL9_MARKETPLACE_IMAGE_OCID "$OL9_MARKETPLACE_IMAGE_OCID" >/dev/null
upsert_cli_env SSH_PRIVATE_KEY_FILE "$SSH_PRIVATE_KEY_FILE" >/dev/null
upsert_cli_env SSH_PUBLIC_KEY_FILE "$SSH_PUBLIC_KEY_FILE" >/dev/null

printf 'AVAILABILITY_DOMAIN=%s\n' "$AVAILABILITY_DOMAIN"
printf 'BASTION_SHAPE=%s\n' "$BASTION_SHAPE"
printf 'OL9_MARKETPLACE_IMAGE_OCID=%s\n' "$OL9_MARKETPLACE_IMAGE_OCID"
printf 'SSH_PUBLIC_KEY_FILE=%s\n' "$SSH_PUBLIC_KEY_FILE"
}

wb07_card01

Create the Oracle Linux 9 bastion VM

This launch command requires Instance Metadata Service Version 2 by setting --instance-options '{"areLegacyImdsEndpointsDisabled":true}'. Do not omit that option in tenancies where IMDSv1 is disabled.

BASH 02 - Create the Oracle Linux 9 bastion VM

Bash
Objective: Create the bastion VM in the assigned PoC compartment through ADMIN_COMPARTMENT_OCID and save the instance OCID. 
wb07_card02() {
clear
  . ~/workbook/env.sh --quiet || return 1

: "${AVAILABILITY_DOMAIN:?Set AVAILABILITY_DOMAIN in ~/workbook/cli.env}"
: "${OL9_MARKETPLACE_IMAGE_OCID:?Set OL9_MARKETPLACE_IMAGE_OCID in ~/workbook/cli.env}"
: "${SSH_PUBLIC_KEY_FILE:?Set SSH_PUBLIC_KEY_FILE in ~/workbook/cli.env}"

BASTION_DISPLAY_NAME="bastion-01"
BASTION_SHAPE="${BASTION_SHAPE:-VM.Standard.E5.Flex}"
BASTION_OCPUS="${BASTION_OCPUS:-1}"
BASTION_MEMORY_GBS="${BASTION_MEMORY_GBS:-16}"

BASTION_VM_OCID="$(
  oci compute instance launch \
    --region "$REGION" \
    --availability-domain "$AVAILABILITY_DOMAIN" \
    --compartment-id "$ADMIN_COMPARTMENT_OCID" \
    --display-name "$BASTION_DISPLAY_NAME" \
    --image-id "$OL9_MARKETPLACE_IMAGE_OCID" \
    --instance-options '{"areLegacyImdsEndpointsDisabled":true}' \
    --shape "$BASTION_SHAPE" \
    --shape-config "{\"ocpus\":$BASTION_OCPUS,\"memoryInGBs\":$BASTION_MEMORY_GBS}" \
    --subnet-id "$SUBNET_ADMIN_OCID" \
    --nsg-ids "[\"$NSG_BASTION_OCID\"]" \
    --ssh-authorized-keys-file "$SSH_PUBLIC_KEY_FILE" \
    --assign-public-ip true \
    --wait-for-state RUNNING \
    --query 'data.id' \
    --raw-output
)"

upsert_cli_env BASTION_VM_OCID "$BASTION_VM_OCID" >/dev/null
printf 'BASTION_VM_OCID=%s\n' "$BASTION_VM_OCID"
}

wb07_card02

Upload SSH files to Object Storage

This step creates a private Object Storage bucket in the assigned PoC compartment through ADMIN_COMPARTMENT_OCID and uploads the bastion SSH private and public key files. Treat the private key object as sensitive material and restrict bucket access with IAM policies.

BASH 03 - Upload SSH files

Bash
Objective: Create the compartment-named SSH key bucket and upload the bastion key files. 
wb07_card03() {
clear
  . ~/workbook/env.sh --quiet || return 1

ADMIN_BUCKET_NAME="${REGION}-${POC_PARENT_COMPARTMENT_NAME}-${POC_COMPARTMENT_NAME}"
OBJECT_STORAGE_NAMESPACE="$(
  oci os ns get \
    --region "$REGION" \
    --query 'data' \
    --raw-output
)"

if ! oci os bucket get \
  --region "$REGION" \
  --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
  --bucket-name "$ADMIN_BUCKET_NAME" >/dev/null 2>&1; then
  oci os bucket create \
    --region "$REGION" \
    --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
    --compartment-id "$ADMIN_COMPARTMENT_OCID" \
    --name "$ADMIN_BUCKET_NAME" \
    --public-access-type NoPublicAccess >/dev/null
fi

if ! oci os object put \
  --region "$REGION" \
  --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
  --bucket-name "$ADMIN_BUCKET_NAME" \
  --name "$(basename "$SSH_PRIVATE_KEY_FILE")" \
  --file "$SSH_PRIVATE_KEY_FILE" \
  --force >/dev/null 2>&1; then
  printf 'STOP: Unable to upload %s.\n' "$SSH_PRIVATE_KEY_FILE" >&2
  return 1
fi

if ! oci os object put \
  --region "$REGION" \
  --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
  --bucket-name "$ADMIN_BUCKET_NAME" \
  --name "$(basename "$SSH_PUBLIC_KEY_FILE")" \
  --file "$SSH_PUBLIC_KEY_FILE" \
  --force >/dev/null 2>&1; then
  printf 'STOP: Unable to upload %s.\n' "$SSH_PUBLIC_KEY_FILE" >&2
  return 1
fi

upsert_cli_env ADMIN_BUCKET_NAME "$ADMIN_BUCKET_NAME" >/dev/null
printf '%-24s | %s\n' \
  "VARIABLE" "VALUE" \
  "------------------------" "-----" \
  "ADMIN_BUCKET_NAME" "$ADMIN_BUCKET_NAME" \
  "PRIVATE_KEY_OBJECT" "$(basename "$SSH_PRIVATE_KEY_FILE")" \
  "PUBLIC_KEY_OBJECT" "$(basename "$SSH_PUBLIC_KEY_FILE")" \
  "STATUS" "uploaded"
printf '\n%s\n' "wb07_card03"
}

SSH connection

BASH 04 - SSH connection

Bash
Objective: Resolve the bastion public IP and open an SSH session as opc. At the first SSH host-verification prompt, type yes and press Enter to trust the bastion host key. 
wb07_card04() {
clear
  . ~/workbook/env.sh --quiet || return 1

BASTION_VNIC_ID="$(
  oci compute instance list-vnics \
    --instance-id "$BASTION_VM_OCID" \
    --query 'data[0].id' \
    --raw-output
)"

BASTION_PUBLIC_IP="$(
  oci network vnic get \
    --vnic-id "$BASTION_VNIC_ID" \
    --query 'data."public-ip"' \
    --raw-output
)"

upsert_cli_env BASTION_PUBLIC_IP "$BASTION_PUBLIC_IP" >/dev/null
ssh -i "$SSH_PRIVATE_KEY_FILE" opc@"$BASTION_PUBLIC_IP"
}

Install SQL client packages for DBA and development work

Oracle's approved Oracle Linux 9 Instant Client repository uses versioned package names. Install the latest packages available from the enabled repository instead of installing RPMs from direct URLs.

Reference:

Topic Source
Oracle Instant Client OL9 repository package names Oracle Instant Client repository for Oracle Linux 9

BASH 05 - Install SQL client packages

Bash
Objective: Install Oracle Instant Client SQL, DBA, development, and JDBC packages on Oracle Linux 9. 
wb07_card05() {
clear
sudo dnf install -y oracle-instantclient-release-26ai-el9
sudo dnf install -y libaio nmap nfs-utils

sudo dnf install -y --allowerasing \
  oracle-instantclient-basic \
  oracle-instantclient-devel \
  oracle-instantclient-jdbc \
  oracle-instantclient-odbc \
  oracle-instantclient-sqlplus \
  oracle-instantclient-tools

SQLPLUS_BIN_DIR="/usr/lib/oracle/23/client64/bin"
PATH="$PATH:$SQLPLUS_BIN_DIR"
export PATH

if ! grep -q "$SQLPLUS_BIN_DIR" ~/.bash_profile 2>/dev/null; then
  printf 'export PATH=$PATH:%s\n' "$SQLPLUS_BIN_DIR" >> ~/.bash_profile
fi

clear
printf '%-28s | %s\n' \
  "VARIABLE" "VALUE" \
  "----------------------------" "-----" \
  "SQLPLUS_BIN_DIR" "$SQLPLUS_BIN_DIR"
sqlplus -v
expdp -help | sed -n '1,3p'
impdp -help | sed -n '1,3p'
}
