Section purpose

This section creates a new container database named CDB01 under the existing dbhome_01 Oracle home on VMCluster-01. The creation request uses the OCI Database CLI database create path, keeps automatic backups disabled, prompts for the database character set, uses the default national character set by omitting the national character-set override, and creates the initial pluggable database PDB01.
OCI CLI 3.73.1 is the target command-line version for this workbook. The command flags used here are limited to the documented oci db database create, oci db database get, oci db database list, and oci db pluggable-database list surfaces.

Required database inputs

Variable Purpose
REGION OCI region loaded by ~/workbook/helpers.sh plus load_cli_env and passed explicitly to OCI CLI commands.
DATABASE_COMPARTMENT_OCID Assigned PoC compartment alias that contains VMCluster-01, dbhome_01, and the new CDB01 database.
VM_CLUSTER_OCID Exadata VM cluster OCID captured in Chapter 08.
DB_HOME_OCID Oracle home OCID for dbhome_01, created in Chapter 08.
DB_VERSION Database version saved when dbhome_01 was created.
CDB_NAME Container database name. Default: CDB01.
PDB_NAME Initial pluggable database name. Default: PDB01.
CDB_ADMIN_PASSWORD Strong password for SYS, SYSTEM, and PDB admin. Workbook value: WelCome#2026_.

Recommended choices

Choice Workbook value Rationale
Create under an existing DB home DB_HOME_OCID for dbhome_01 Keeps database software lifecycle separate from database creation and reuses the home prepared in Chapter 08.
Initial PDB PDB01 Creates the default application pluggable database during CDB provisioning.
Automatic backups Disabled Matches the requested lab state. Enable backups later only after validating backup destination, retention, and recovery requirements.
Character set Prompted during creation Accept the OCI Database default AL32UTF8, choose WE8MSWIN1252, or specify another supported database character set. The default path omits characterSet from the create payload.
National character set Default Omits --ncharacter-set; OCI Database defaults to AL16UTF16.
Database unique name Service default Omits dbUniqueName from the create payload so OCI assigns the default unique name.
Time zone Region default The documented database creation command does not expose a database time-zone override. The workbook does not pass a time-zone value; the database is created on the VM cluster using the service defaults for the region and cluster context.
Password handling Environment variable plus JSON payload Avoids placing the password directly on the shell command line while still keeping the workbook executable in Cloud Shell.

BASH 03 - Create CDB01 with PDB01

BASH 03 - Create CDB01 with PDB01

Bash
Objective: Submit the CDB01 create request in dbhome_01 with PDB01, no automatic backup, and the selected database character set. 
. ~/workbook/env.sh --quiet || return 1
wb10_card03() {

CREATE_CDB_JSON="$HOME/workbook/create-cdb01.json"
CREATE_CDB_OCID_FILE="$HOME/workbook/create-cdb01-ocid.txt"

missing=0
for name in REGION VM_CLUSTER_OCID DB_HOME_OCID CDB_NAME PDB_NAME CDB_ADMIN_PASSWORD; do
  eval "value=\${$name:-}"
  if [ -z "$value" ]; then
    printf 'Missing required variable: %s\n' "$name" >&2
    missing=1
  fi
done

if [ "$missing" -ne 0 ]; then
  printf 'Run BASH 01 and BASH 02 before creating CDB01.\n' >&2
  return 1
fi

printf 'Select the database character set for %s.\n' "$CDB_NAME"
printf '  1) Accept OCI Database default AL32UTF8\n'
printf '  2) Use WE8MSWIN1252\n'
printf '  3) Specify another supported character set\n'
printf '  4) Cancel database creation\n'
printf 'Enter choice [1]: '
read -r CHARACTER_SET_CHOICE
CHARACTER_SET_CHOICE="${CHARACTER_SET_CHOICE:-1}"

case "$CHARACTER_SET_CHOICE" in
  1)
    CDB_CHARACTER_SET="AL32UTF8"
    CDB_CHARACTER_SET_MODE="DEFAULT"
    ;;
  2)
    CDB_CHARACTER_SET="WE8MSWIN1252"
    CDB_CHARACTER_SET_MODE="EXPLICIT"
    ;;
  3)
    printf 'Enter database character set: '
    read -r CDB_CHARACTER_SET
    CDB_CHARACTER_SET="$(printf '%s' "$CDB_CHARACTER_SET" | tr '[:lower:]' '[:upper:]')"
    if [ -z "$CDB_CHARACTER_SET" ]; then
      printf 'Character set is required when choice 3 is selected.\n' >&2
      return 1
    fi
    CDB_CHARACTER_SET_MODE="EXPLICIT"
    ;;
  4)
    clear
    printf 'CDB01 creation canceled by user.\n'
    printf '\n%s\n' "wb10_card03"
    return 1
    ;;
  *)
    printf 'Invalid character set choice: %s\n' "$CHARACTER_SET_CHOICE" >&2
    return 1
    ;;
esac

jq -n \
  --arg db_home_id "$DB_HOME_OCID" \
  --arg vm_cluster_id "$VM_CLUSTER_OCID" \
  --arg db_name "$CDB_NAME" \
  --arg pdb_name "$PDB_NAME" \
  --arg admin_password "$CDB_ADMIN_PASSWORD" \
  --arg character_set "$CDB_CHARACTER_SET" \
  --arg character_set_mode "$CDB_CHARACTER_SET_MODE" \
  '{
    source: "NONE",
    dbHomeId: $db_home_id,
    vmClusterId: $vm_cluster_id,
    dbName: $db_name,
    pdbName: $pdb_name,
    adminPassword: $admin_password,
    autoBackupEnabled: false,
    runImmediateFullBackup: false
  }
  | if $character_set_mode == "EXPLICIT"
    then . + {characterSet: $character_set}
    else .
    end' > "$CREATE_CDB_JSON"

CDB_OCID="$(
  oci db database create \
    --region "$REGION" \
    --from-json "file://$CREATE_CDB_JSON" \
    --query 'data.id' \
    --raw-output
)"

if [ -z "$CDB_OCID" ] || [ "$CDB_OCID" = "null" ]; then
  printf 'Unable to capture CDB_OCID from the create response.\n' >&2
  return 1
fi

printf '%s\n' "$CDB_OCID" > "$CREATE_CDB_OCID_FILE"
upsert_cli_env CDB_OCID "$CDB_OCID" >/dev/null
upsert_cli_env CDB_CHARACTER_SET "$CDB_CHARACTER_SET" >/dev/null
upsert_cli_env CDB_CHARACTER_SET_MODE "$CDB_CHARACTER_SET_MODE" >/dev/null
clear
printf '%-24s | %s\n' \
  "VARIABLE" "VALUE" \
  "------------------------" "-----" \
  "CDB_OCID" "$CDB_OCID" \
  "CDB_CHARACTER_SET" "$CDB_CHARACTER_SET" \
  "CDB_CHARACTER_SET_MODE" "$CDB_CHARACTER_SET_MODE"
printf '\n%s\n' "wb10_card03"
}

BASH 04 - Validate CDB01 lifecycle

BASH 04 - Validate CDB01 lifecycle

Bash
Objective: Confirm the CDB01 lifecycle state before continuing. 
. ~/workbook/env.sh --quiet || return 1
wb10_card04() {

if [ -z "${CDB_OCID:-}" ]; then
  printf 'Missing required variable: CDB_OCID. Run BASH 03 before validating CDB01.\n' >&2
  return 1
fi

clear
DB_JSON="$(
  oci db database get \
    --region "$REGION" \
    --database-id "$CDB_OCID" \
    --query 'data' \
    --output json
)"

DB_ROW="$(
  printf '%s' "$DB_JSON" \
  | jq -r --arg now "$(date -u +%s)" '
      def epoch($stamp):
        $stamp
        | sub("\\.[0-9]+"; "")
        | sub("\\+00:00$"; "Z")
        | fromdateiso8601;
      def elapsed($start; $finish):
        if ($start // "") == "" then "unknown"
        else
          (($finish | tonumber) - epoch($start)) as $seconds
          | if $seconds < 60 then "\($seconds)s"
            elif $seconds < 3600 then "\(($seconds / 60) | floor)m \($seconds % 60)s"
            else "\(($seconds / 3600) | floor)h \((($seconds % 3600) / 60) | floor)m"
            end
        end;
      [
        ."db-name",
        ."db-unique-name",
        elapsed(."time-created"; $now),
        ."lifecycle-state"
      ] | @tsv'
)"

if [ -z "$DB_ROW" ]; then
  printf 'Unable to build CDB01 lifecycle summary from OCI response.\n' >&2
  return 1
fi

IFS="$(printf '\t')" read -r DB_NAME_VALUE DB_UNIQUE_NAME_VALUE ELAPSED_TIME_VALUE DB_STATE_VALUE <<EOF
$DB_ROW
EOF

printf '%-12s | %-24s | %-14s | %s\n' \
  "DB_NAME" "DB_UNIQUE_NAME" "ELAPSED_TIME" "STATE" \
  "------------" "------------------------" "--------------" "-----" \
  "$DB_NAME_VALUE" "$DB_UNIQUE_NAME_VALUE" "$ELAPSED_TIME_VALUE" "$DB_STATE_VALUE"
printf '\n%s\n' "wb10_card04"
}

BASH 08 - Download bastion and cluster SSH keys

Objective: Create ~/keys, download the bastion VM key and cluster first-node key from the existing ADMIN_BUCKET_NAME Object Storage bucket, and set permission 700 on the directory and every downloaded file. 
. ~/workbook/env.sh --quiet || return 1
wb10_card08() {

KEY_DIR="$HOME/keys"
BASTION_KEY_SOURCE_FILE="${SSH_PRIVATE_KEY_FILE:-}"
CLUSTER_KEY_SOURCE_FILE="${EXADATA_SSH_PRIVATE_KEY_FILE:-}"
BASTION_KEY_OBJECT_NAME="$(basename "$BASTION_KEY_SOURCE_FILE")"
CLUSTER_KEY_OBJECT_NAME="$(basename "$CLUSTER_KEY_SOURCE_FILE")"
BASTION_KEY_FILE="$KEY_DIR/$BASTION_KEY_OBJECT_NAME"
CLUSTER_KEY_FILE="$KEY_DIR/$CLUSTER_KEY_OBJECT_NAME"

missing=0
for name in REGION ADMIN_BUCKET_NAME SSH_PRIVATE_KEY_FILE EXADATA_SSH_PRIVATE_KEY_FILE; do
  eval "value=\${$name:-}"
  if [ -z "$value" ]; then
    printf 'STOP: Missing required variable: %s\n' "$name" >&2
    missing=1
  fi
done

if [ "$missing" -ne 0 ]; then
  printf 'Run the bastion and Exadata key cards first so ADMIN_BUCKET_NAME, SSH_PRIVATE_KEY_FILE, and EXADATA_SSH_PRIVATE_KEY_FILE are present in ~/workbook/cli.env.\n' >&2
  return 1
fi

OBJECT_STORAGE_NAMESPACE="$(
  oci os ns get \
    --region "$REGION" \
    --query 'data' \
    --raw-output
)"

if [ -z "$OBJECT_STORAGE_NAMESPACE" ] || [ "$OBJECT_STORAGE_NAMESPACE" = "null" ]; then
  printf 'STOP: Unable to resolve Object Storage namespace for region %s.\n' "$REGION" >&2
  return 1
fi

mkdir -p "$KEY_DIR"
chmod 700 "$KEY_DIR"

oci os object get \
  --region "$REGION" \
  --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
  --bucket-name "$ADMIN_BUCKET_NAME" \
  --name "$BASTION_KEY_OBJECT_NAME" \
  --file "$BASTION_KEY_FILE"

oci os object get \
  --region "$REGION" \
  --namespace-name "$OBJECT_STORAGE_NAMESPACE" \
  --bucket-name "$ADMIN_BUCKET_NAME" \
  --name "$CLUSTER_KEY_OBJECT_NAME" \
  --file "$CLUSTER_KEY_FILE"

chmod 700 "$KEY_DIR" "$KEY_DIR"/*

upsert_cli_env OBJECT_STORAGE_NAMESPACE "$OBJECT_STORAGE_NAMESPACE" >/dev/null

clear
printf '%-34s | %s\n' \
  "FIELD" "VALUE" \
  "----------------------------------" "-----" \
  "KEY_DIR" "$KEY_DIR" \
  "ADMIN_BUCKET_NAME" "$ADMIN_BUCKET_NAME" \
  "BASTION_KEY_FILE" "$BASTION_KEY_FILE" \
  "CLUSTER_KEY_FILE" "$CLUSTER_KEY_FILE" \
  "DIRECTORY_PERMISSION" "700" \
  "FILE_PERMISSION" "700"
printf '\n%s\n' "wb10_card08"
}

BASH 13 - Allow SSH to the bastion NSG

To tighten bastion access, add a single IPv4 address as a /32 SSH ingress rule on the bastion network security group. This card creates the reusable script ~/workbook/allow-bastion-ssh-source.sh, resolves the current Cloud Shell public IP by default, and calls the reusable script with that IP address. The default rule description is Allow SSH from approved source IP - Cloud Shell. To allow a different source, pass the IP address as the first parameter, for example wb10_card13 <approved_source_ip>; that custom rule description is Allow SSH from approved source IP - Custom. This workbook uses NSG_BASTION_OCID for bastion access control, so the reusable script updates the bastion NSG used by the VM. #!/bin/sh

allow_bastion_ssh_source() {
  . "$HOME/workbook/env.sh" --quiet || return 1

  SOURCE_IP="${1:-}"
  SOURCE_IP_MODE="${2:-provided}"
  WORKBOOK_DIR="${WORKBOOK_DIR:-$HOME/workbook}"
  RULE_FILE="$WORKBOOK_DIR/nsg-bastion-ssh-source-rule.json"
  RULES_JSON="$WORKBOOK_DIR/nsg-bastion-existing-rules.json"
  RULE_ID_FILE="$WORKBOOK_DIR/nsg-bastion-ssh-source-rule-id.txt"
  SOURCE_SSH_CIDR="$SOURCE_IP/32"
  RULE_DESCRIPTION="Allow SSH from approved source IP - Custom"

  if [ "$SOURCE_IP_MODE" = "current Cloud Shell public IP" ]; then
    RULE_DESCRIPTION="Allow SSH from approved source IP - Cloud Shell"
  fi

  missing=0
  for name in REGION NSG_BASTION_OCID SOURCE_IP; do
    eval "value=\${$name:-}"
    if [ -z "$value" ]; then
      printf 'STOP: Missing required variable: %s\n' "$name" >&2
      missing=1
    fi
  done

  case "$SOURCE_IP" in
    *[!0-9.]*|*.*.*.*.*|.*|*.)
      printf 'STOP: Source IP is not a valid IPv4 address: %s\n' "$SOURCE_IP" >&2
      missing=1
      ;;
  esac

  if [ "$missing" -ne 0 ]; then
    printf 'Run BASH 05 networking cards and confirm NSG_BASTION_OCID is present in ~/workbook/cli.env.\n' >&2
    return 1
  fi

  oci network nsg rules list \
    --region "$REGION" \
    --nsg-id "$NSG_BASTION_OCID" \
    --direction INGRESS \
    --all \
    --output json \
    > "$RULES_JSON"

  EXISTING_RULE_ID="$(
    jq -r \
      --arg cidr "$SOURCE_SSH_CIDR" \
      '.data[]
      | select(.direction == "INGRESS")
      | select(.protocol == "6")
      | select(.source == $cidr)
      | select(."source-type" == "CIDR_BLOCK")
      | select(."tcp-options"."destination-port-range".min == 22)
      | select(."tcp-options"."destination-port-range".max == 22)
      | .id' "$RULES_JSON" | head -n 1
  )"

  if [ -z "$EXISTING_RULE_ID" ]; then
    cat > "$RULE_FILE" <<EOF
[
  {
    "description": "$RULE_DESCRIPTION",
    "direction": "INGRESS",
    "isStateless": false,
    "protocol": "6",
    "source": "$SOURCE_SSH_CIDR",
    "sourceType": "CIDR_BLOCK",
    "tcpOptions": {
      "destinationPortRange": {
        "min": 22,
        "max": 22
      }
    }
  }
]
EOF

    oci network nsg rules add \
      --region "$REGION" \
      --nsg-id "$NSG_BASTION_OCID" \
      --security-rules "file://$RULE_FILE" \
      --query 'data[0].id' \
      --raw-output > "$RULE_ID_FILE"

    NSG_RULE_STATUS="added"
    NSG_RULE_ID="$(cat "$RULE_ID_FILE")"
  else
    NSG_RULE_STATUS="already present"
    NSG_RULE_ID="$EXISTING_RULE_ID"
  fi

  clear
  printf '%-28s | %s\n' \
    "FIELD" "VALUE" \
    "----------------------------" "-----" \
    "SOURCE_IP_MODE" "$SOURCE_IP_MODE" \
    "RULE_DESCRIPTION" "$RULE_DESCRIPTION" \
    "SOURCE_IP" "$SOURCE_IP" \
    "SOURCE_SSH_CIDR" "$SOURCE_SSH_CIDR" \
    "NSG_BASTION_OCID" "$NSG_BASTION_OCID" \
    "NSG_RULE_STATUS" "$NSG_RULE_STATUS" \
    "NSG_RULE_ID" "$NSG_RULE_ID" \
    "RULE_FILE" "$RULE_FILE" \
    "SCRIPT_FILE" "$HOME/workbook/allow-bastion-ssh-source.sh"
}
