Section purpose

This section loads the workbook shell environment created in Chapter 05 and prints the required prerequisite variables. Run it first in OCI Cloud Shell or another shell where OCI CLI authentication has already been configured and ~/workbook/bin/env.sh already exists. Complete the OCI PoC RunBook through Chapter 05 before starting this Exadata workbook so the required VCN, subnets, route baseline, gateways, and NSGs are already available.

Variables expected in cli.env

The following variables should already exist in ~/workbook/cli.env before this Exadata workbook begins.

Variable Purpose
TENANCY_ID Tenancy OCID used by identity, compartment, and service-limit checks.
REGION OCI region where all commands execute.
POC_PARENT_COMPARTMENT_NAME Expected parent compartment label, normally Partner.
POC_PARENT_COMPARTMENT_OCID Parent compartment OCID for (root)/Partner.
NETWORK_COMPARTMENT_OCID Compartment that owns VCN, subnet, route, gateway, and NSG artifacts.
DATABASE_COMPARTMENT_OCID Compartment that owns Vault-01, VMCluster-01, dbhome_01, and database resources.
ADMIN_COMPARTMENT_OCID Compartment that owns the bastion VM and administration resources.
SECURITY_COMPARTMENT_OCID Compartment that owns OCI Vault, KMS keys, and secrets for database credentials.
SUBNET_ADMIN_OCID Subnet used by the bastion VM.
SUBNET_DBCLIENT_OCID Client subnet for VMCluster-01.
SUBNET_DB_BACKUP_OCID Backup subnet for VMCluster-01.
SUBNET_DBTOOLS_OCID Database tools subnet OCID.
NSG_BASTION_OCID NSG applied to the bastion VM VNIC.
NSG_DATABASE_CLIENT_OCID NSG applied to the database client network.
NSG_DBTOOLS_OCID NSG applied to private database tooling endpoints.

The following variables are optional workbook defaults. Later chapters reuse them from ~/workbook/cli.env when present and apply the documented default only when the variable is not already set.

Variable Default Purpose
EXADATA_STORAGE_GB 512 High capacity storage for Vault-01.
LICENSE_MODEL BRING_YOUR_OWN_LICENSE Database license edition model for VMCluster-01.
DB_VERSION 23.26.0.0.0 Oracle Database version for dbhome_01.

BASH 01 - Load workbook shell and base preflight

BASH 01 - Load workbook shell and base preflight

Bash
Objective: Load the Chapter 05 workbook environment, then display the active workbook directories, PoC compartment, and VCN preflight values. 
wb06_card01() {
  clear
  . ~/workbook/bin/env.sh --quiet || return 1
  printf '%-29s | %s\n' \
    "VARIABLE" "VALUE" \
    "-----------------------------" "-----" \
    "WORKBOOK_DIR" "${WORKBOOK_DIR:-<not_set>}" \
    "JSON_DIR" "${JSON_DIR:-<not_set>}" \
    "REPORT_DIR" "${REPORT_DIR:-<not_set>}" \
    "TENANCY_ID" "${TENANCY_ID:-<not_set>}" \
    "REGION" "${REGION:-<not_set>}" \
    "POC_PARENT_COMPARTMENT_NAME" "${POC_PARENT_COMPARTMENT_NAME:-<not_set>}" \
    "POC_COMPARTMENT_NAME" "${POC_COMPARTMENT_NAME:-<not_set>}" \
    "POC_COMPARTMENT_OCID" "${POC_COMPARTMENT_OCID:-<not_set>}" \
    "VCN_NAME" "${VCN_NAME:-<not_set>}" \
    "VCN_CIDR" "${VCN_CIDR:-<not_set>}"
  printf '\n%s\n' "wb06_card01"
}
